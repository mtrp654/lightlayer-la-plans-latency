## 二、免备案免的到底是什么

免的是工信部 ICP 备案，前提只有一条：网站托管在美国，且不经过中国大陆的节点。域名解析到洛杉矶的 IP，绑好就能开站，没有等待期，也不需要提交营业执照和法人材料。

有四种情况会让备案义务反过来找上你：

1. **服务器搬回大陆。** 网站迁到北京、上海等地的云服务器，必须先备案，再在 30 日内完成公安联网备案，否则可能被停机。
2. **启用中国大陆的 CDN 节点。** 源站还在美国，只要加速或安全流量经过大陆节点，服务商就会要你出示备案号。这条最容易被忽略，很多人买完 CDN 才发现卡在这里。
3. **使用 .cn 或 .中国 域名。** 这类域名必须完成实名认证，否则解析可能被冻结。实名不等于备案，但它是一道独立的手续。
4. **在中国境内提供经营性服务。** 在线教育、收费会员这类业务需要 ICP 许可证，比备案更严格。

用 .com、.net 这类国际域名，只做域名实名，不涉及备案流程。不备案也不影响搜索引擎收录，只是部分国内广告投放和支付平台开户时会要备案号，那属于平台规则。

还有一层常被省略：在美国服务器上收集中国用户的订单、邮箱、地址，仍然受《个人信息保护法》约束，跨境传输可能需要签标准合同或做安全评估。免备案解决的是上线流程，不解决数据合规。

## 三、国内访问延迟的真实预期

洛杉矶到国内的延迟，正常时段在 150–180ms，移动网络有时能跑到 130ms 出头。商家宣传里"50ms 到大陆"的说法，通常是最优节点、最优时段测出来的最低值，规划建站按 150ms 上下算比较稳。香港节点能压到 30–50ms，代价是同配置月付价格普遍是美国的数倍。

100 多毫秒的差距，对 WordPress 这类动态站，普通访客基本感知不到。页面加载的瓶颈通常在 PHP 执行和数据库查询，不在网络往返那 100ms。真正吃延迟的是另一类业务：实时音视频、游戏服务器、面向国内用户的在线交易系统，这些放美国会明显难受，该选香港或日本节点。外贸独立站、英文博客、跨境工具站，访客本来就在境外，美国节点的带宽和单价优势更实在。

## 五、下单前要问清的五件事

**1. 原生 IP 是否默认。** 行业里有的节点默认给原生 IP，有的要联系客服额外付费开通，日本节点尤其常见。做本地化业务、对 IP 归属敏感的，下单前确认。

**2. 换 IP 收不收费。** 部分商家对最低配机型换 IP 收费，只有 IP 本身故障才免费；其他配置免费换一次，第二次起计费。多账号业务对 IP 干净度敏感，这条要先问。

**3. 退款窗口有几天。** 各家差异很大，有的云服务器 3 天内无理由退款，有的独立服务器一旦开通就不退不换。LightLayer 的公开渠道里没有查到明确的退款条款，下单前开工单问清楚，别默认有冷静期。

**4. Windows 是否另收授权费。** Linux 是默认系统，装 Windows Server 通常要单独买授权，而且 1核1G 跑 Windows 会卡，官方一般建议 2核2G 以上再装。

**5. 续费价是不是首期价。** 这是长期建站最该算的一笔账。有的商家活动套餐承诺续费同价，首单什么折扣续费还是什么折扣；也有商家首年低价、第二年回到原价。核对方法很简单：在结算页找到续费价，按"首年实付 + 第二年实付"加总算两年总成本，别看首年折算出来的月均价。举例，月付 $4 跑两年是 $96；若年付首年 $24.99、续费涨到 $48/年，两年合计 $72.99，仍然更便宜，但如果续费涨到 $96/年，两年就是 $120.99，反而贵过月付。
